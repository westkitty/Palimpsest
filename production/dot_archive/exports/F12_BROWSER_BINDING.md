# F12 · Living Book native Blender port

The authored F12 source is the reviewed Q4 master, SHA-256
`7b5ee828f289889bf274589897042b093de194ce099fb738c3e06b7344ec5377`.
The exporter creates a browser derivative without changing the archived
master. Export is 1,473,700 bytes. It removes the studio, former Kail
caption/identity/status and associated index tick, and all prior closing
imprint geometry and print. The separate character-free coda remains the
only Living Book destination for the exact closing sentence.

- Six original **Signed but not joined** cut horizon leaves, three per
  page. The split still reads above an uninterrupted book gutter.
- A binds the two actual printed claim cards to independent reversible
  local translation tracks. The cards stay separate even at rest; their
  legible headings are unchanged.
- B mounts the original Living/Archive symbolic study behavior onto the
  Blender B context plate. It still toggles off the filament and lowers
  its indicator independently of A and C. This is nonoperational imagery.
- C uses the actual reviewed frame 1–67 crease and fixed pin, not a
  substituted viewport animation. It opens to the named public Syrin 4
  record, without inventing dates or casualty totals. Both the source
  cover and its pull tab respond to touch.
- Existing Living-only recruitment roles and endorsement stamp remain
  mounted; role timing, tooling and language have not changed. The stamp
  occupies the outer foot margin, off the moving folder. The separate
  coda is untouched. The archive remains unchanged; the Living path will
  not construct the historical Kail model even while loading or if the
  GLB fails, and never emits its caption in Living copy.

Validation: `npm run lint`, `npm run build`,
`node --test tests/challenger-f12-asset.test.mjs`, and the
`tests/challenger-f12-browser.mjs` local WebGL smoke. Set
`PALIMPSEST_PREVIEW_URL`, `PALIMPSEST_CHROME_PATH`,
`PALIMPSEST_PLAYWRIGHT_MODULE`, or `PALIMPSEST_PROOF_DIR` as needed.
