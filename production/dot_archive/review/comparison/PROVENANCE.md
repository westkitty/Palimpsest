# Baseline screenshot provenance

These screenshots are **real captures of the existing Living Book WebGL renderer** in open-book overview, not Blender re-creations, mockups, or captures of the archival fallback. Chrome for Testing headless shell 143.0.7499.4 ran actual WebGL through software ANGLE/SwiftShader. The game's own software-renderer detection renders at 0.85 scale and omits certain live-shadow effects. The captured browser viewport is 1100×720 at device scale 1 and default book camera. Keyboard focus is visible at the canvas border. Optional reading panels remain closed; no miniature-only testimony is opened.

**Source route:** https://westkitty.github.io/Palimpsest/folio-vnext.html . The [official GitHub Pages deployment](https://github.com/westkitty/Palimpsest/actions/runs/44996118884) completed successfully on `41dddee6383d94e8ce0f68303a506cd9290225ee`; that also matches repository `main` at capture. In this headless environment Chrome did not accept the proxy certificate. The live production HTML and its two content-hashed JS bundles were downloaded through the environment's trusted HTTPS transport and replayed **byte-for-byte** through a temporary local loopback server, without editing or rebuilding them, accepting a browser certificate warning, or changing the site. `mirror-hashes.sha256` identifies the exact source payloads; the deployment receipt and raw served HTML or JS may be retained independently.

For each folio, `FNN_Neutral.png` is the ready/open overview with no mechanism acts, and `FNN.png` is the closest supported current runtime state after the public keyboard sequence recorded in `baseline-manifest.json`. There is no assumption that the browser and Blender use the same camera or identical mechanics. The manifest records URL, title, mechanism state, observed A/B/C controls, viewport, hashes and verified WebGL for each. Any old Mother/Egg archival F03 from Drive is a different edition and is excluded from the matched set.
