# Palimpsest — Second-quarter Blender candidates (F04–F06)

A separate, editable proof set for the second three of twelve folios. Start with the review reel, then compare individual proof stills and open each Blender file to inspect the folds. These studies are not approved replacement assets, a built game, or a live integration. The first quarter and source archives remain untouched.

| Folio | What changed in the candidate study | Where it would slot in |
|---|---|---|
| F04 | A six-panel cardstock logistics strip makes the existing “observe → verify → act → record” lesson physical; the surrounding colony and Codec stations anchor it in the original folio. | F04 in `FoliosWar1.ts`, its existing C strip, A/B retained per local slot map. |
| F05 | A rough physical red ring, layered material-processing records, and a paper inspection mechanism. Preserve source-vs-doctrine separation. | F05 in `FoliosWar1.ts` and `livingStagecraft.ts`, without recasting its existing A/B/C operations. |
| F06 | An indexed left-hand chronology drum, two source-exported campaign specimens at center, and a physical six-leaf cumulative-loss ledger on the right. Unknown counts stay blank. | F06 in `FoliosWar1.ts` and its later stagecraft; retain the full runtime chronology and creature registry. |

All scenes use meaningful hinge lines and visible cut stock rather than a paper texture over a solid figurine. Candidate alignment is editorial and kinematic, not a manufacturing certification. No canon approvals, no audio, no new casualty numbers, and no changes to the live reader. See each folder’s source and QA notes for exact proven states, omissions, and suggested integration surface.

## Future integration boundary
Living Book and archival Atlas currently instantiate the same F05 class. If integration is separately authorized, inject Living-only visuals from `src/vnext/laterFolioScenes.ts`; preserve the shared default and the archive. Keep new specimen meshes inside the existing B-bound picker groups. For any exported GLB pair, record base pivot, +Y-up axis, bounding boxes, source and export hashes, and compare scale and clearance beside the conduit and inspection doors. Give imported textures explicit lifetime ownership and exercise leave/return twice. This package makes no GLB import or runtime change.
