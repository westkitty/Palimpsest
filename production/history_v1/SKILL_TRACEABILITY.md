Rules are paraphrased for Antigravity; this is **not** a copy of private ChatGPT plugin Skills.

- Starsilk canon governance, image preflight, closed-world/ontology checks => source and identity locks in root AGENTS.md, Drakken manifest and build Skill.
- Midcentury-projector-film => Administration instructional grammar, 4:3 folios, age-softened cels, gentle narration, real pointer mechanisms.
- Three.js engineering/performance => reuse book engine, correct pivot/disposal/quality handling, runtime validation.
- Operational-state/purpose/authorization => existing app safeguards, separate Git branch and non-destructive migration.
- Production/asset provenance => original-vs-generated status, Drive URLs and private ZIP SHA-256 manifest.
- Completion/traceability/QA => 12-folio and 36-interaction matrix, real browser replay and no false completion.
- Cross-runtime skill adapter => AGENTS.md plus .agents/skills folder, **not** assumed automatic access to connected ChatGPT tools.
