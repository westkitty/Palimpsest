# F03 · The Notebook Program physical workshop

Living Book only. The approved V03 Blender stage, linkage clips and
interaction state remain intact. No archive, canon, narration or release
changes.

1. **Vault:** Three folded-paper sleeves use the original family colors and
   four-notch ink registers. The selected sleeve becomes a ramp; the
   selected folded globe emerges, unfolds to its full silhouette and rolls
   into the foreground cradle.
2. **Source:** Syrrian IV retains airborne cut-paper islands; Nimbus III
   retains twilight bands and bioluminescent print; Cirrus I keeps its
   translucent continental facets and strata. All are the existing
   Dossier-bound folded globe geometry.
3. **Press:** The die's perimeter comes from a projected geometric hull of
   the actual selected source, not a generic circle. The source must be
   seated before the die lowers onto the waiting paper.
4. **Variant:** The printed card leaves the die flat. Its actual
   destination globe gores bend, with visible creases, into the bounded
   variant. Existing Notebook family/generation data supplies the shape.
5. **Read:** Source and output hold side by side with the same four-notch
   seal. The title lettering remains, while the two instructional
   captions are unnecessary on the model. Keyboard, touch and
   accessibility labels stay in place. Low-motion mode shows the same
   end state without any middle movement.

Checks: `npm run lint`, `npm run build`, and
`node tests/challenger-f03-workshop-browser.mjs` with a built Vite
preview and the optional browser/proof environment variables.
